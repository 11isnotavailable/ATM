# ATM: Action-Consistency Transfer Matrix for Diagnosing and Improving Latent World Models

This repository contains the official implementation of **ATM (Action-Consistency Transfer Matrix)**, a lightweight post-hoc framework for diagnosing action-identifiable transition structure in latent world models.

ATM compares action semantics between real encoded transitions and model-predicted transitions through a (2 \times 2) cross-domain inverse-probing matrix. The framework supports:

* transition-level representation diagnostics;
* checkpoint and model-variant screening;
* cross-domain failure-mode analysis;
* Action-Identifiable Transition Supervision (AITS).
